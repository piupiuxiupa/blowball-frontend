# Design

## Context

消息区已经使用 TanStack Virtual 做动态高度虚拟滚动。用户消息在 `MessageList` 中被归并为 `role === 'user'` 的持久化块，流式段只追加在列表尾部。用户块拥有稳定 id（历史消息）或回合内稳定 id（乐观消息），可作为导航锚点。

## Goals / Non-Goals

- Goals: 提供类似 Codex 的左侧等距刻度轨道，支持 hover 预览、当前回合标记、点击跳转和目标高亮。
- Goals: 在虚拟列表下跳到正确的行，不破坏流式自动贴底。
- Non-Goals: 不按真实滚动高度拉伸刻度；不做消息搜索或助手消息索引。

## Realization

- 锚点从 `blocks` 而不是 `items` 派生：流式 token 只改变尾部 segments，用户锚点数组保持引用稳定，避免每次节流渲染重复计算当前刻度。
- 轨道刻度固定 10px 间距、按距离 26/20/14/10/6px 形成悬停涟漪；刻度区最多 500px，超出时自身滚动并隐藏滚动条。
- 当前回合以消息区视口 40% 线为判据：顶部保留上文、底部阅读输出，40% 比顶边更接近实际阅读位置。
- 点击时通过 `rowVirtualizer.scrollToIndex(index, { align: 'center' })` 跳转。若目标已完整可见则不重复滚动；跳往历史位置时同步关闭“贴底跟随”，避免流式输出把目标行拉回底部。
- 目标用户气泡用 ring 高亮约 1.8 秒；ring 是 box-shadow，不引起虚拟行高度重测或布局抖动。
- 会话切换时重置当前刻度、高亮与轨道状态，防止跨会话残留。

## Risks / Trade-offs

- 未测量行的虚拟高度仍是估算，首次远距离跳转可能由 virtualizer 的动态测量校正一帧；点击后的目标 ring 帮助用户确认最终位置。
- 等距刻度不表示真实滚动高度；这是刻意取舍，换取长会话中稳定、可扫读的边框定位。
- 键盘逐刻度移动会在长会话产生较多 tab stop；当前以清晰 aria 标签和当前态换取实现简单，后续可升级为方向键组件。
